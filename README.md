# 훌라 편대 시뮬레이터

Hula 드론 블록코딩 파일(JSON)을 3D로 재생하고, 드론 사이 간격·높이·위아래 겹침을 점검하는 웹 페이지입니다.

- 만든이: 민병국 (OrangeMBK)
- 바닥: 실제 QR 매트와 같은 모양(QR 30cm 간격, 가로 14개 × 세로 7개, X 0~3.9m · Y 0~1.8m)
  - 원점 (0,0) = 왼쪽 아래 100번 QR, 번호 = (행+1)×100 + 열 (예: 304 = (1.2, 0.6))
  - 드론은 +Y(0,0 → 0,30 방향, 관객 쪽)를 바라보고 출발
  - 관객은 700번 줄 너머에서 바라봄 → 위·정면 화면 모두 관객 쪽에서 본 방향으로 보여 줌
- 기본 예제: `orange빛군무` 6대 LED 군무 (색이 바뀌며 파도·계단·V자·기울어진 원·하트·피라미드·꽃·화살표, 드론끼리 위아래로 겹치지 않음)
- 드론 번호표와 후광이 그 순간의 LED 색으로 바뀌어 보입니다.
- 사용법: 페이지를 열고 **JSON 파일 열기**로 Hula 앱에서 저장한 파일을 불러옵니다.
- `index.html` 한 파일에 모든 기능이 들어 있어 인터넷 없이 파일만 열어도 작동합니다.
- AI 편대 코치는 Claude에서 열었을 때만 쓸 수 있습니다.
